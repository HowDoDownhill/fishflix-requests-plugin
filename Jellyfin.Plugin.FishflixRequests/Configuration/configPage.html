Fishflix Requests

Shows Jellyseerr requests grouped by user, with their progress. Users open the requests page at /FishflixRequests/Page while signed in to Jellyfin web.

The address Jellyfin can reach Jellyseerr (or Overseerr) at.
In Jellyseerr: Settings → General → API Key.
When off, non-admin users only see their own requests. Admins always see everything.
How long results are reused before Jellyseerr is asked again.
The newest requests are loaded first.
